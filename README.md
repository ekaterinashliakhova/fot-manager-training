# ФОТ · Практика КМ

Обучающая платформа для ККСБ, РГС и ММБ: по одному бизнес-кейсу из трёх этапов для каждого сегмента, материалы для обучения, интерактивная 3D-лиса и учебный ГигаПротокол ЛИСА.

Это статический сайт без серверной части. Для сборки нужен только Python 3. На сайте нет паролей, токенов или учётных данных GitHub. Внешние ссылки на корпоративные ресурсы требуют соответствующего доступа.

## Публикация в GitHub Pages

1. Создайте репозиторий `fot-manager-training` и загрузите содержимое этой папки в ветку `main`, включая `.github/workflows/pages.yml`. Для бесплатного GitHub Pages используйте публичный репозиторий.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Откройте **Actions → Publish GitHub Pages → Run workflow → main → Run workflow**. После успешной публикации ссылка появится в задании `deploy` и в **Settings → Pages**.
4. Следующие изменения в `main` будут публиковаться автоматически.

Адрес проекта: https://ekaterinashliakhova.github.io/fot-manager-training/ . Сборка автоматически использует путь, который сообщает GitHub Pages: подойдут другое имя репозитория, корневой сайт `USERNAME.github.io` и собственный домен.

## Локальная проверка

Для корневого адреса:

```sh
python scripts/build_pages.py --base-path /
python -m http.server 8000 --directory _site
```

Откройте `http://localhost:8000/`.

Для проверки адреса с именем репозитория:

```sh
python scripts/build_pages.py --base-path /fot-manager-training/ --output preview/fot-manager-training
python -m http.server 8000 --directory preview
```

Откройте `http://localhost:8000/fot-manager-training/`. Изменяйте файлы в `dist/`, затем запускайте сборку заново. `_site/` — результат сборки, его не нужно коммитить.

## Что входит в проект

- `dist/` — все страницы, сценарии, изображения, PDF, шрифты и 3D-библиотека. У страниц есть собственные `index.html`, поэтому прямые ссылки работают без серверных перенаправлений.
- `scripts/build_pages.py` — адаптация ссылок, маршрутов, импортов и ресурсов к адресу GitHub Pages; исходные сценарии не меняются.
- `.github/workflows/pages.yml` — автоматическая сборка и публикация.
- `ASSETS.md` — сведения о визуальных материалах и библиотеках.

Прогресс и имя участника сохраняются в localStorage браузера отдельно для каждого сегмента. При смене домена накопленный на прежнем сайте прогресс автоматически не переносится. Общего журнала результатов и серверной учётной записи нет.

Итоговый этап `/final/` проверяет прохождение кейса с оставшейся жизнью. Ссылка на итоговое тестирование в Пульсе ещё ожидается; передача результатов в Пульс не настроена. ЛИСА имитирует запись встречи и не записывает микрофон.

## Лиса · помощник ККСБ

На главном экране ККСБ нажатие на 3D-лису открывает чат. Отдельной плашки нет; персонаж доступен также с клавиатуры и в уменьшенном виде при прокрутке. Слева — сворачиваемая история с датой создания. Карточка клиента относится к конкретному чату; сообщения и карточки сохраняются в localStorage этого браузера. Между устройствами история не синхронизируется.

Сервер размещается на https://fot-practice-km.c8cpv86h5k.chatgpt.site/api/lisa . `agent/worker.js` — код API, `agent/knowledge.json` — 19 распознанных страниц двух предоставленных презентаций с датой и ссылками. `scripts/build-site-worker.py` собирает Worker для Sites; GitHub Pages по-прежнему публикует только интерфейс из `dist/`.

Для ответов необходим серверный секрет OPENAI_API_KEY. Значения ключей не хранятся в GitHub и браузере. Необязательный OPENAI_MODEL по умолчанию gpt-5-mini. Без модели интерфейс честно показывает ожидание подключения; карточка и калькулятор работают. Ответы ИИ не имитируются.

Контекст последних 40 сообщений и карточка передаются в каждом запросе. Ставки для расчётов задаются явно; неизвестное не приравнивается к нулю. База кэшбэка вводится отдельно от ФОТ. Кэшбэк сотрудникам не считается доходом компании. Разница комиссий не объявляется полной выгодой. Для длинных переговоров фиксируйте важные вводные в карточке.

По запросу модель может искать по официальным сайтам банков. Текущие условия не считаются известными из материалов октября 2026. OCR таблиц требует сверки цифр по PDF. Полная база RAG ещё ожидается.
